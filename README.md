# 📊 US Restaurant Menu Analytics

A Python-based data analytics project that explores US restaurant menu data to identify **menu pricing patterns, menu item distribution, restaurant distribution, and regional trends**.

The project follows a complete data analytics workflow, from **data loading and preprocessing to exploratory analysis, visualization, statistical analysis, and final reporting**.

### 🔗 Dataset Source

Dataset: [US Restaurant Menus – Hugging Face](https://huggingface.co/datasets/AnyStackLabsdev/souslab-us-restaurant-menus?library=datasets)

### 📂 Dataset Description

The **US Restaurant Menu Analytics** dataset contains restaurant menu information from across the United States. It consists of **10,000 rows and 17 columns**, covering menu items, sections, prices, descriptions, availability, and geographical information. The dataset contains both **categorical and numerical variables** and is suitable for analyzing restaurant menu patterns and pricing trends.

### 🎯 Project Objective

To analyze US restaurant menu data using Python and identify meaningful insights related to **menu pricing, menu item distribution, restaurant distribution, geographical patterns, and regional trends** through data cleaning, exploratory analysis, statistical techniques, and visualization.

### 📌 Project Phases

* **Phase 1 – Initial Data Understanding:** Loaded the dataset and examined its structure, dimensions, columns, data types, missing values, and initial records.
* **Phase 2 – Data Preprocessing:** Handled missing values, removed duplicate records, dropped unnecessary columns, and prepared the dataset for analysis.
* **Phase 3 – Exploratory Data Analysis (EDA):** Performed univariate, bivariate, and multivariate analysis to identify patterns, relationships, distributions, trends and visualizations to communicate findings effectively.
* **Phase 4 – Overall Summary & Final Recommendations:** Interpreted the analytical results, identified key insights, examined patterns and outliers, and presented conclusions, recommendations, and future scope.

### 🔍 Key Areas of Analysis

* Menu price distribution and pricing patterns
* Price categories and menu item counts
* Average menu prices across US states
* Restaurant and menu item distribution by state
* Out-of-stock status and menu pricing
* Geographical distribution of restaurants
* Relationship between menu price and menu item count
* State-wise and price-category analysis
* Correlation analysis of numerical variables
