# 📊 US Restaurant Menu Analytics

A Python-based data analytics project that explores US restaurant menu data to identify **menu pricing patterns, menu item distribution, restaurant distribution, and regional trends**.

The project covers the complete data analytics workflow, from **data loading and preprocessing to exploratory analysis, statistical analysis, visualization, and final reporting**.

### 📂 Dataset Description

The **US Restaurant Menu Analytics** dataset contains restaurant menu information from across the United States. It consists of **10,000 rows and 17 columns**, covering menu items, sections, prices, descriptions, availability, and geographical information. The dataset contains both **categorical and numerical variables** and is suitable for analyzing restaurant menu patterns and pricing trends.

### 🔗 Dataset Source

Dataset: [US Restaurant Menus – Hugging Face](https://huggingface.co/datasets/AnyStackLabsdev/souslab-us-restaurant-menus?library=datasets)

### 🔍 Key Areas of Analysis

* Menu price distribution and pricing patterns
* Price categories and menu item counts
* Average menu prices across US states
* Restaurant and menu item distribution by state
* Out-of-stock status and menu pricing
* Geographical distribution of restaurants
* Relationships between menu price and menu item count
* State-wise and price-category analysis
* Correlation analysis of numerical variables

### 🎯 Project Objective

To transform raw restaurant menu data into meaningful insights through data cleaning, exploratory analysis, statistical techniques, and visualization.

### 📌 Project Phases

* **Phase 1 – Data Loading & Overview:** Loaded the dataset and examined its structure, columns, data types, and initial records.
* **Phase 2 – Data Cleaning & Preprocessing:** Handled missing values, removed duplicates, cleaned data, and prepared variables for analysis.
* **Phase 3 – Exploratory Data Analysis (EDA):** Performed univariate, bivariate, and multivariate analysis to identify patterns and relationships.
* **Phase 4 – Data Visualizations:** Created charts and geographical visualizations to communicate analytical findings clearly.
* **Phase 5 – Analysis & Reporting:** Interpreted the results, identified key insights, discussed patterns and outliers, and presented conclusions and recommendations.
